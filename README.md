## Flagship WordPress Plugins

### 1. AutoSSL & Let's Encrypt Manager for cPanel (`v1.2.2`)
Issue, renew, and monitor 90-day Let's Encrypt & AutoSSL certificates directly from WordPress via the **cPanel UAPI (Port 2083)** and a built-in **Direct Let's Encrypt ACME v2 HTTP-01 Fallback Client**.
- **AES-256-CBC Encrypted API Tokens:** Uses WordPress security salts—never stores plain-text cPanel passwords.
- **Built-in ACME v2 Engine:** Automatically completes HTTP-01 domain validation, generates a 2048-bit RSA key & CSR, issues a 90-day Let's Encrypt certificate, and installs it via `SSL::install_ssl` when shared hosts disable cPanel's native `autossl` feature.
- **Port 443 TLS Pre-Flight Guard:** Verifies valid HTTPS response before allowing 301 HTTPS redirection.
- **Direct Download:** [https://wpaiplugins.online/api/download/autossl-lets-encrypt-manager-for-cpanel](https://wpaiplugins.online/api/download/autossl-lets-encrypt-manager-for-cpanel)

### 2. Safe UI Adjuster — Conversational AI UI Agent (`v1.1.2`)
Chat with an AI assistant and point-and-click any element (`⊕`) on your WordPress site to adjust CSS, layout, DOM announcement banners/text, and Block Editor/Role permissions—with **zero risk of breaking your site**.
- **Floating Frontend Live Chat Drawer + Point-and-Click Element Picker (`⊕`)**
- **Split-Screen AI Chat Studio in WP Admin** with live responsive preview (Desktop / Tablet / Mobile), Active Rules Inspector, and 20-Turn Snapshot History.
- **100% Local Smart Command Engine + Multi-Provider BYOK AI** (Google Gemini, OpenAI, Anthropic Claude).
- **4-Layer Zero-Breakage Safety Guard:** Admin-Only Preview Mode staging, balanced-brace CSS syntax validation, 1-click Undo on every chat message, and the `?wsua_safe_mode=1` emergency URL bypass.
